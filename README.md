# ForgetIt
A project about a personalised checklist used for travel and daily activities

## Project Vision
To transform the frustration of forgetting essential items into a seamless and stress-free experience by providing a personalised checklist that adapts to individual needs and preferences.

## Core Features
- Create personalised trip profiles
- Build dynamic checklists based on each profile
- Smart suggestions for commonly forgotten items
- Local notifications to remind users of pending tasks
- Simple and intuitive user interface

## Technology Stack
- **Frontend:** .NET MAUI
- **Language:** C#
- **Database:** SQLite
- **Platforms:** Android, iOS, Windows, macOS
