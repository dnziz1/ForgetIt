# User Stories - Travel Bot

## Epic 1: Trip Planning
- **As a user**, I want to create a new trip itinerary so that I can organize my travel plans. With a name, destination, and dates.
- **As a user**, I want to edit my trip details so that I can update my plans as needed.
- **As a user**, I want to delete a trip so that I can remove trips that are no longer relevant.
- **As a user**, I want to view all my upcoming trips and past trips so that I can keep track of my travel schedule.

## Epic 2: Checklist Management
- **As a user**, I want to add items to a packing checklist so that I can ensure I don't forget anything important.
- **As a user**, I want to mark items as packed so that I can keep track of what I've already packed.
- **As a user**, I want to remove items from the checklist so that I can keep it up to date.
- **As a user**, I want to view my packing checklist so that I can see what I need to pack for my next trip.

## Epic 3: Notifications and Reminders
- **As a user**, I want to receive reminders for upcoming trips so that I can prepare in advance.
- **As a user**, I want to see a final check-in interface on trip day

## MVP Scope
- [ ] All Epic 1 user stories
- [ ] All Epic 2 user stories
- [ ] Basic notification for trip reminders (Epic 3, first user story only)
